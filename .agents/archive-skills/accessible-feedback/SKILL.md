---
name: accessible-feedback
description: "Build reusable transient feedback or OTP/password controls using the project's existing UI."
---

Read [the project profile](../../project.md) first.

Read the project UI, theme and locale rules. Search existing primitives first. Keep focus and accessible names intact, expose errors as text, and test keyboard input, paste, autofill, RTL and narrow screens. Use reduced-motion variants. Prepare optional audio only in a user gesture and allow silent operation. Success can dismiss automatically; actionable failures must stay available. Keep feedback independent of feature-specific API calls.
